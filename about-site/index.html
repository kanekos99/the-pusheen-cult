The Pusheen Cult Archive

This site is an almost one-to-one recreation of the original Pusheen Cult Weebly website , which has sadly become defunct (and ultimately inaccessible) due to Weebly no longer operating in the webmaster's country of origin. This new site is coded from scratch using Eleventy . As a disclaimer, the content of this site is intended to be a joke.

Other than the complete migration of pages, comments and user submissions, this new site also includes slightly better responsiveness than the original. It will most not likely be updated any further, but user submissions - such as on the Prayers , Testimonials and Membership pages - will still remain open.

Any user submissions will also be automatically added to the website, but any potentially sensitive content will be removed. If you would like your submission or comment to be removed, you can... send me PR on Github ...?
